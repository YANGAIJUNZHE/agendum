# 日常使用

新版安卓 App 支持日程管理与离线编辑。在电脑「设置 → 手机日程同步」配对后，可以在手机新建、修改、完成、恢复和删除日程；电脑关机时先存手机，重新连接后同步。完整操作与冲突处理见 [手机日程同步](mobile-sync.md)。

主导航包括 **待办、最近推送、收件箱、设置**。电脑宽屏时固定在左侧，窄屏时显示在顶部。

## 电脑工作区

首页默认显示待处理事项，按最近到期排列，未设日期的排在最后。顶部用「清单／月历」切换同一批事项的呈现方式，用日期、状态和搜索缩小范围；清单还可改按最近添加排序。月历不显示无日期事项，会提示数量。新建入口和「清空已完成」保留在工具区，后者需要再次点击确认，清理所有已完成、已忽略、已过期事项，不受当前筛选范围限制。

顶部「新建待办」直接打开弹窗，填写内容即可创建，也可设置截止时间、勾选「仅设置日期」或补充备注。卡片上的「编辑」使用相同弹窗；列表更新不会打断编辑。取消、关闭或 Esc 离开时，有未保存内容会先询问是否放弃；保存失败保留输入并显示原因，成功后自动关闭。新建后会清除筛选并定位新事项。

任务标题在前，原文和纠错按需展开，编辑直接放在卡片操作区。筛选后可点「清除筛选」恢复默认的全部日期、待处理和最近到期排序；月历「今天」返回当前月份。月历点日期展开当天事项，再点事项标题回清单处理；置顶标题也会清除筛选并定位原事项。电脑宽屏辅助栏独立滚动，展开不推动主区；侧栏到顶或到底后，继续同向滚动会带动整页，鼠标无需移出侧栏。接入进度放在可展开的指引中，日历不要求先登录 QQ。

右侧「辅助面板」保留置顶日程、快捷操作、本周小结、QQ 接入、订阅群、服务自检、关于与支持。点击面板标题折叠或展开；点击「整理」后，可以拖动「拖动」按钮排序，也可以使用「上移」「下移」（支持键盘）。点「完成」退出整理，点「恢复默认」恢复默认顺序与折叠状态。顺序和折叠状态只保存在当前浏览器；更换浏览器或清除站点数据后恢复默认。初次需要登录时 QQ 接入保持展开，已连接后默认收起；手动折叠优先于后台状态刷新。

## 分级设置

侧栏跨越顶部或底部时会连续带动页面。鼠标滚轮使用短缓动；如果偏好直接响应，可在「设置 → 常用设置 → 外观与布局」关闭轻微动效，系统的减少动效设置也会生效。

设置页一次只显示一个子页面。先选分类，再选具体设置；也可在「查找设置」中输入关键词。分类切换不会保存或清空输入，仍需使用各功能的保存按钮。进入设置后，首页概览和辅助面板收起，完整功能保留在对应页面。

| 一级分类 | 二级页面 |
| --- | --- |
| 常用设置 | 外观与布局、托管与启动 |
| 消息来源 | QQ 与订阅群、微信、钉钉、学习通、历史回溯 |
| 通知与提取 | 消息推送、AI 摘要、识别规则 |
| 日程与数据 | 手机日程同步、日历订阅、数据备份 |
| 系统与帮助 | 首次配置、运行信息、版本更新、服务公告、关于与支持 |

「QQ 与订阅群」与首页 QQ 面板使用同一份控件和状态。向导、更新提示、日历二维码等快捷入口会自动打开对应子页面，无需手动查找。

首页不再显示「还有几项没配好」的常驻提醒。需要检查接入时，打开「设置 → 系统与帮助 → 首次配置」，点「查看状态」展开检查结果；也可重新运行首次向导。

## 第一次（大概五分钟）

| # | 做什么 | 在哪 |
| --- | --- | --- |
| 1 | 手机 QQ 扫码登录 | 页面「QQ 接入」那块 |
| 2 | 勾选要盯的群，保存 | 同一块下方的群列表 |
| 3 | 手机浏览器打开同一个地址，「添加到主屏幕」 | 手机浏览器菜单 |
| 4 | 订阅 iPhone 日历（可选） | 设置 → 日程与数据 → 日历订阅，用相机扫卡片 |
| 5 | 配 AI 摘要（可选） | 设置 → 通知与提取 → AI 摘要，选服务商、粘 key、保存并测试 |
| 6 | 配推送（可选） | 设置 → 通知与提取 → 消息推送，按通道说明填写 |

不配 5 和 6 也能用：没有 AI 就走本地规则摘要，没有推送就靠网页和日历。

## 待办

通过「日期」选择全部日期、今天、未来 7 天、已逾期或未设日期，通过「状态」选择待处理、待确认、已完成或全部状态。「待处理」包含尚未完成和待确认的事项。

- 点左边的方块打勾完成。
- 「查看完整原文」看那条群消息的原话。
- 「纠错」改摘要或分类。
- 卡片上的「紧急」可以手动标或取消，再点一次回到跟随 AI 判断。
- 「+」手动加一条。
- 「置顶」把某件事钉在右侧「置顶日程」面板里，已完成的任务要先恢复待办才能置顶。

月历每格最多显示 3 条带时刻的事项，超过显示 `+N`；点那一天会把当天全部事项展开。手机上同样通过「月历」切换，无需再展开一次。

## 收件箱

**回溯聊天记录**默认收起，需要补充过去的消息时再展开：勾群、选日期，先点「① 回溯聊天记录」把消息抓下来，再点「② 提取通知」让模型逐条判定。只抓得到 NapCat 本地缓存里还剩的消息，越早越可能没了；点「探测最早时间」能看实际边界。已有回溯或提取任务运行时会自动展开，显示进度和取消入口。

**通知收件箱**支持按「确定通知 / 疑似通知 / 已转待办」、群和关键词筛选，「清除筛选」恢复全部消息。每条直接显示正文预览、判定理由和来源，长消息可展开全文。想留的点「转成待办」，转换后点「查看待办」定位事项；不想要的点「删除」——第一次点只提示确认，4 秒内再点一次才真删。删的是那条消息和收件箱记录，已经转好的待办留着。

操作结果显示在页面底部的浮动提示中，滚到长页面下方也能看到。成功提示 5 秒后收起，失败提示保留，可关闭；提供「重试」时可原地重试。

## 群订阅

「QQ 接入」下面那块群列表：勾选就是订阅，取消就是不再监控，保存后立刻生效，不用重启。

白名单的意思是「只处理勾过的群」，没勾的一律忽略——所以闲聊群不会污染你的待办。

## 推送

「截止提醒」要发得出去，至少得配一个通道。设置里列了四种：WxPusher、Server 酱、PushPlus、企业微信/钉钉群机器人。点开一种，旁边写着去哪拿、复制什么、贴哪里，填完点「保存」立刻生效，再点「发一条测试消息」看手机收没收到。

输入框留空表示这项不动；页面只回显尾四位，不显示明文。一个通道都没配时，右栏「服务自检」里的消息推送会标黄，并给一个「去设置」的按钮。

## 手机端

1. 手机和电脑连同一个 Wi-Fi。
2. 浏览器打开 `http://<电脑局域网IP>:8766/`。电脑 IP 用 `ipconfig` 看「IPv4 地址」。
3. 菜单里「添加到主屏幕」，之后像 App 一样点开。

用流量访问要先开通公网入口（Tailscale Funnel），见 [常见问题](faq.md)。

## iPhone 日历

设置 →「iPhone 日历订阅」，卡片上有一张二维码，用 **iPhone 相机**扫（别用微信扫），会跳到「订阅日历」确认页。卡片会按「公网地址 → 局域网地址」的顺序给可用地址，想换就点地址下面的「局域网 …」按钮，二维码跟着换。

手动路径：iPhone「设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历」，服务器填卡片上的地址。

同步规则：网页上标记完成的，日历里那条变成「已完成」；被忽略或过期的变成「已取消」。刷新频率由 iOS 决定，想立刻刷新就在日历 App 里下拉。

## 托管：让 NapCat 和你的电脑版 QQ 共用一台电脑

同一个 QQ 号不能在两个电脑端同时在线，这是腾讯服务端的规则。托管就是帮你轮班：开始托管先关电脑版 QQ、再启动 NapCat；结束托管停掉 NapCat、把 QQ 开回来。

三个入口效果一样：网页顶栏的「开始托管 / 结束托管」按钮、右下角托盘菜单、设置里的四个勾选框。

| 勾选项 | 默认 | 作用 |
| --- | --- | --- |
| 自动退出电脑版 QQ | 开 | 开始托管时关掉你的 QQ |
| 托管结束后恢复电脑版 QQ | 开 | 结束托管时把 QQ 开回来 |
| 启动时自动开始托管 | 关 | 一启动就进托管 |
| 开机自动启动Agendum | 关 | 写当前用户的开机启动项，不需要管理员 |

点「开始托管」会停顿十几秒，它在关 QQ，不是卡住。

结束托管会先确认本安装的托管 QQ 已退出，再按设置恢复普通 QQ。若提示仍有残留、查询失败或超时，托管状态会保留，普通 QQ 暂不自动打开；处理提示后可再点一次「结束托管」。引擎启动器已经退出时，后台 QQ 仍会被识别，同一资料目录不会重复启动。

## 退出

托盘图标 →「退出（结束托管并关闭）」。直接关浏览器标签页不会关掉软件，它还在后台跑。

退出时托管清理最多使用五秒查询和结束进程，未能确认清理成功会写入启动器日志、保留托管状态并继续退出。此时不会自动恢复普通 QQ，可重新打开Agendum重试结束托管。

服务要是自己崩了（不是从托盘退出的），看门狗会在 5 分钟内把它拉起来；从托盘「退出」主动关掉的不会被拉起，直到你下次自己启动。

配置项都在 [配置](config.md)，界面报错见 [常见问题](faq.md)。
